# 📸 Instagram Database Clone Using MySQL

## 📌 Project Overview
This project is an Instagram-inspired relational database system developed using MySQL. It simulates the basic functionality of a social media platform, including users, posts, likes, comments, followers, and following relationships.

The main objective of this project is to demonstrate practical SQL skills, database design, and data analysis.

## 🛠️ Technologies Used
- MySQL
- MySQL Workbench
- VS Code
- Git & GitHub

## 🗂️ Database Tables
The project consists of the following tables:

1. **Users** – Stores user information.
2. **Posts** – Stores posts created by users.
3. **Likes** – Tracks likes on posts.
4. **Comments** – Stores comments on posts.
5. **Follows** – Manages follower and following relationships.

## 📊 SQL Concepts Used

- Database Design
- Primary Keys & Foreign Keys
- Joins (INNER JOIN, LEFT JOIN)
- GROUP BY and HAVING
- Aggregate Functions (COUNT, AVG, MAX)
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions (ROW_NUMBER, RANK, DENSE_RANK)
- CASE WHEN
- EXISTS and NOT EXISTS
- ORDER BY and LIMIT

## 🚀 How to Run This Project

1. Clone this repository:
2. Open MySQL Workbench.
3. Execute `schema.sql` to create the database and tables.
4. Execute `insert_data.sql` to insert sample records.
5. Execute `queries.sql` to perform SQL analysis.

## 📈 Project Analysis

This project includes SQL analysis such as:

- Finding posts with the highest number of likes.
- Identifying users with the most followers.
- Calculating total posts per user.
- Finding users with no posts.
- Analyzing monthly posting trends.
- Ranking users based on engagement.
- Finding the top 3 most-liked posts per user.
